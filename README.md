📦 Sistema de Controle de Estoque e Vendas

Este projeto é um sistema desenvolvido em C++ como parte da avaliação final do curso. O objetivo foi criar uma aplicação de console para gerenciar o estoque de uma loja, calcular preços de venda e simular relatórios, aplicando os conceitos fundamentais da linguagem.

🚀 Funcionalidades

O sistema conta com um menu interativo que permite:

Cadastro de Produtos: Armazenamento de nome, preço de custo e quantidade em vetores dinâmicos.

Cálculo de Preço de Venda: Utiliza lógica matemática (potenciação) para definir o preço final com base na margem de lucro.

Relatório de Estoque: Listagem completa com alertas automáticos ("Estoque Baixo" ou "Em Falta").

Simulação de Vendas: Projeção de vendas para 12 meses para análise de faturamento.

Área do Gerente: Acesso restrito via senha (com limite de 3 tentativas) para funções administrativas.

Análise de Desempenho: Cálculos estatísticos sobre o inventário.

🛠️ Tecnologias e Conceitos Aplicados

Este projeto foi construído para demonstrar o domínio dos seguintes tópicos:

Estruturas de Controle: if, else, switch case.

Laços de Repetição: do-while (menu), for (relatórios), while (validação de senha).

Estruturas de Dados: Uso de std::vector para armazenamento dinâmico.

Matemática: Biblioteca <cmath> para funções de potência (pow) e raiz quadrada (sqrt).

Modularização: Implementação de funções separadas para organização do código.

⚙️ Como Executar

Para rodar o projeto, você precisa de um compilador C++ (como G++).

Clone este repositório:

git clone [https://github.com/SEU-USUARIO/nome-do-repositorio.git](https://github.com/SEU-USUARIO/nome-do-repositorio.git)


Compile o arquivo:

g++ estoque_vendas.cpp -o sistema


Execute o programa:

No Windows: sistema.exe

No Linux/Mac: ./sistema
